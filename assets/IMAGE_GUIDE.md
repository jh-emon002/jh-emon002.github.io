Paths in `settings.js` have the `assets/` prefix. For example, copy `wifi8-beamforming.jpg` to `assets/projects/wifi8-beamforming.jpg`.

To use a different filename or add several images to the same card, change its `images` list in `settings.js`, or use `?edit=1` to edit the image paths in the Customize panel. You can use `.png` and `.webp` files too, as long as the configured extensions match the real files.
